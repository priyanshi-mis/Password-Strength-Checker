# SecureCheck – Password Security Analyzer

SecureCheck is a Python-based desktop application that analyzes password strength and provides suggestions to improve password security.

## Features
- Real-time password strength analysis
- Weak, Fair, Good and Strong classification
- Password requirements checklist
- Show/Hide password option
- Secure random password generator
- Copy generated password
- Common password detection
- Modern dark-themed GUI

## Technologies Used
- Python
- Tkinter
- Regular Expressions
- Secrets Module

## How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder.
4. Run:

```bash
python password_checker.py
```

## Privacy

Password analysis is performed locally. Passwords are not uploaded to an external server.

**Note:** This is an educational password strength checker, not a complete security auditing tool.
